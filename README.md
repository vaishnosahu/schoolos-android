# SchoolOS Android

SchoolOS Mobile 3.3.0 production native Android shell.

Production builds use package `com.schooloss.mobile`, target SDK 35, HTTPS-only networking, WebView debugging disabled, and repository-secret-backed release signing.

Release candidate build handoff refreshed for production signing.

Finance Center is available in the authenticated mobile shell and uses the same server-authoritative finance workflow as SchoolOS web.
